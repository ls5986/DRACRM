# Debt Resolution CRM

A modern, interactive CRM application for debt resolution companies to manage clients, credit pulls, and backend integrations.

## Features

- Dashboard with client overview and analytics
- Client management with detailed profiles
- Credit pull functionality with decision engine
- Backend integration management
- Modern, responsive UI built with React and Tailwind CSS

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

## Running the Application

Start the development server:
```bash
npm start
```

The application will be available at http://localhost:3000

## Building for Production

Create a production build:
```bash
npm run build
```

## Project Structure

- `src/components/DebtResolutionCRM.jsx` - Main application component
- `src/index.js` - Application entry point
- `src/index.css` - Global styles and Tailwind imports
- `tailwind.config.js` - Tailwind CSS configuration
- `postcss.config.js` - PostCSS configuration

## Technologies Used

- React 18
- Tailwind CSS
- Lucide React (for icons)
- React Scripts
